✦ New Feature

Inkori Tutorial System

Every interface now has a built-in step-by-step guide. No more guessing how to switch modes, use panels, or navigate the workspace.

▶ See it in action

Overview

What the Tutorial System Does

A small tutorial button now lives in every major interface. Click it to open a step-by-step modal that walks you through exactly how that section works — with tips, keyboard shortcuts, and callouts pointing to specific UI elements.

📖

Step-by-Step Walkthroughs

Each tutorial is broken into focused steps — one concept at a time. Navigate forward and back, or jump to any step by clicking the progress bar.

👆

Highlight Callouts

Steps that reference a specific button or UI element show a purple callout saying "Look for: X" so you know exactly where to look on screen.

💡

Pro Tips on Every Step

Each step includes an amber tip box with insider knowledge — keyboard shortcuts, best practices, and things that aren't obvious from the UI alone.

⌨️

Keyboard Navigation

Use ← → arrow keys to move between steps. Press Escape to close. The modal remembers where you left off within a session.

Switch to Script Mode

Click the "Script" button in the top toolbar (or press ⌘2 on Mac / Ctrl+2 on Windows). Script Mode formats your writing like a screenplay — Scene Headings, Action lines, Character names, and Dialogue blocks.

👆

Look for: Script button in the toolbar

💡

Press Tab inside Script Mode to cycle through block types: Scene → Action → Character → Dialogue → Parenthetical → Transition.
